# 凌犀零代码平台 - 应用功能说明

## 功能概述

本项目实现了一个基于AI对话的零代码应用生成平台，用户可以通过与AI对话来创建网站应用，并可以部署和管理这些应用。

## 主要功能

### 1. 主页 (/)
- **用户提示词输入**：用户可以输入应用描述，创建新应用
- **我的应用列表**：展示当前用户创建的应用，支持分页和搜索
- **精选应用列表**：展示平台精选的应用，支持分页和搜索

### 2. 应用对话页 (/app/chat/:id)
- **对话区域**：用户可以与AI对话，生成和修改应用代码
- **实时流式输出**：AI回复以流式方式实时显示
- **网页预览**：代码生成完成后，右侧显示生成的网站效果
- **部署功能**：用户可以部署应用，获取可访问的URL

### 3. 应用详情页 (/app/detail/:id)
- **应用基本信息**：展示应用名称、创建者、创建时间等
- **应用描述**：显示应用的初始提示词
- **部署状态**：显示应用是否已部署及部署时间
- **应用预览**：如果应用已部署，显示应用预览
- **操作按钮**：提供对话、编辑、删除等操作

### 4. 应用编辑页 (/app/edit/:id)
- **基本信息编辑**：用户可以编辑应用名称
- **管理员高级编辑**：管理员可以编辑应用封面和优先级
- **只读信息**：显示应用的创建者、创建时间等只读信息

### 5. 应用管理页 (/admin/appManager) - 仅管理员
- **应用列表**：展示所有应用，支持分页和搜索
- **批量操作**：管理员可以删除任意应用
- **精选设置**：管理员可以设置应用优先级，将应用设为精选
- **快速操作**：提供查看详情、对话、编辑等快捷操作

## 技术实现

### 前端技术栈
- Vue 3 + TypeScript
- Ant Design Vue
- Pinia (状态管理)
- Vue Router (路由管理)
- Axios (HTTP请求)
- Vite (构建工具)

### 后端接口
- 用户认证和管理
- 应用CRUD操作
- AI对话接口 (SSE流式输出)
- 应用部署接口
- 静态资源服务

### 关键实现点

1. **SSE流式对话**
   - 使用EventSource实现与服务器的SSE连接
   - 实时接收和显示AI回复
   - 处理连接错误和重连逻辑

2. **权限控制**
   - 基于用户角色的权限管理
   - 路由守卫实现页面级权限控制
   - 组件级权限控制显示/隐藏功能

3. **响应式设计**
   - 适配不同屏幕尺寸
   - 移动端友好的交互设计
   - 灵活的布局系统

## 使用流程

1. **创建应用**
   - 在主页输入应用描述
   - 点击"创建应用"按钮
   - 自动跳转到对话页面

2. **生成应用**
   - 在对话页面与AI交互
   - AI实时生成代码
   - 右侧预览区域显示效果

3. **部署应用**
   - 点击"部署应用"按钮
   - 获取部署后的URL
   - 在新窗口中访问应用

4. **管理应用**
   - 在应用详情页查看应用信息
   - 在应用编辑页修改应用信息
   - 管理员可在应用管理页管理所有应用
