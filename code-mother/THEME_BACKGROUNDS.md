# 凌犀零代码平台 - 主题背景系统

## 概述

本项目为日间和夜间模式设计了优雅的渐变背景，完美契合"凌犀"品牌的科技感和专业性。

## 背景设计理念

### 日间模式 🌤️
**设计主题**: 天空蓝渐变 - 清新、明亮、充满活力

**色彩方案**:
```css
linear-gradient(135deg, 
  #e0f2fe 0%,   /* 浅天蓝 - 清晨的天空 */
  #bae6fd 20%,  /* 亮天蓝 - 明媚的午后 */
  #7dd3fc 40%,  /* 中天蓝 - 清澈的湖水 */
  #38bdf8 60%,  /* 鲜艳天蓝 - 科技感 */
  #0ea5e9 80%,  /* 深天蓝 - 专业感 */
  #0284c7 100%  /* 海洋蓝 - 沉稳可靠 */
)
```

**特点**:
- 由浅到深的天空蓝渐变
- 给人清新、开阔、充满希望的感觉
- 15秒缓慢动态渐变，增加生动感
- 适合长时间工作使用，不刺眼

### 夜间模式 🌙
**设计主题**: 深邃星空渐变 - 神秘、沉稳、专注

**色彩方案**:
```css
linear-gradient(135deg, 
  #0f172a 0%,   /* 深蓝黑 - 午夜星空 */
  #1e293b 25%,  /* 深石板蓝 - 深海 */
  #0c4a6e 50%,  /* 深海蓝 - 宇宙深处 */
  #075985 75%,  /* 深天蓝 - 黎明前 */
  #0369a1 100%  /* 品牌蓝 - 凌犀主色 */
)
```

**特点**:
- 深邃而富有层次的蓝黑渐变
- 营造专注、沉浸的工作氛围
- 20秒更缓慢的动态渐变
- 减少眼疲劳，适合夜间使用

## 技术实现

### 1. 全局样式配置

在 `src/styles/global.css` 中定义：

```css
/* 日间模式渐变 */
--gradient-bg-light: linear-gradient(135deg, 
  #e0f2fe 0%, #bae6fd 20%, #7dd3fc 40%, 
  #38bdf8 60%, #0ea5e9 80%, #0284c7 100%
);

/* 夜间模式渐变 */
--gradient-bg-dark: linear-gradient(135deg, 
  #0f172a 0%, #1e293b 25%, #0c4a6e 50%, 
  #075985 75%, #0369a1 100%
);
```

### 2. BasicLayout 应用

在 `src/layouts/BasicLayout.vue` 中：

```vue
<style scoped>
/* 日间模式 */
.app-layout:not(.dark-mode) {
  background: linear-gradient(135deg, 
    #e0f2fe 0%, #bae6fd 20%, #7dd3fc 40%, 
    #38bdf8 60%, #0ea5e9 80%, #0284c7 100%
  );
  background-attachment: fixed;
  background-size: 200% 200%;
  animation: gradientShift 15s ease infinite;
}

/* 夜间模式 */
.app-layout.dark-mode {
  background: linear-gradient(135deg, 
    #0f172a 0%, #1e293b 25%, #0c4a6e 50%, 
    #075985 75%, #0369a1 100%
  );
  background-attachment: fixed;
  background-size: 200% 200%;
  animation: gradientShift 20s ease infinite;
}

@keyframes gradientShift {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}
</style>
```

## 动画细节

### gradientShift 动画
```css
@keyframes gradientShift {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}
```

**参数说明**:
- **background-size: 200% 200%**: 渐变扩大到2倍，为动画提供移动空间
- **animation-duration**: 
  - 日间模式: 15秒（较快，活力感）
  - 夜间模式: 20秒（较慢，沉稳感）
- **animation-timing-function: ease**: 平滑缓动
- **animation-iteration-count: infinite**: 无限循环

### 固定背景
```css
background-attachment: fixed;
```
- 背景固定不随滚动移动
- 增强视觉深度感
- 提供更好的阅读体验

## 主题切换

### 切换方式
用户可通过 Header 右上角的主题切换按钮在日间/夜间模式间切换。

### 切换效果
```css
transition: background 0.5s ease;
```
- 0.5秒平滑过渡
- 避免突兀的颜色跳变
- 提供流畅的用户体验

### 日间模式

- **主要文字**: #EEEEEE (浅灰白)
- **次要文字**: #C9D1D9 (灰白)

## 品牌色彩体系

### 核心品牌色
- **主色**: #3b82f6 (科技蓝)
- **辅色**: #0ea5e9 (天空蓝)

- 日间: 从天空蓝到海洋蓝
- 夜间: 从深蓝黑到品牌蓝

## 性能优化

### CSS 优化
- 使用 `transform` 代替 `background-position` 动画（GPU 加速）
- 使用 `will-change` 提示浏览器优化
- 背景固定减少重绘

### 渲染优化
```css
.app-layout {
  will-change: background;
  transform: translateZ(0);
}
```

## 设计建议

### 颜色选择
1. **保持色系统一**: 选择同一色系的渐变
2. **对比度适中**: 避免过于鲜艳或暗沉
3. **品牌一致性**: 包含品牌主色调
4. **可读性优先**: 确保文字清晰可读

### 动画速度
- **活泼场景**: 10-15秒
- **专业场景**: 15-20秒
- **沉稳场景**: 20-30秒

### 渐变方向
- **135deg**: 对角渐变，动感流畅
- **180deg**: 垂直渐变，稳重大气
- **90deg**: 水平渐变，宽广开阔
