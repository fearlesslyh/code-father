## 详细功能说明

### 场景 1: 外部观测黑洞

当你首次进入页面时，你会看到：
- 🌌 **宇宙星空**: 15000+ 颗不同颜色的星星
- ⚫ **黑洞核心**: 中央的暗黑球体（事件视界）
- 🌀 **吸积盘**: 围绕黑洞旋转的橙黄色炽热气体盘
- 💫 **引力透镜**: 背景星光被黑洞引力弯曲的效果

**操作提示**:
```
滚轮向下滚动 = 靠近黑洞（缩放范围: 2-20）
滚轮向上滚动 = 远离黑洞
点击星星 = 查看星体数据
```

### 场景 2: 星星交互

**如何触发**:
1. 移动鼠标到星空区域
2. 点击任意星星

**交互效果**:
- 🌟 星星亮度瞬间提升
- 📊 弹出半透明蓝色 HUD 信息框
- 显示内容：
  - 星体编号 (STAR-XXXX)
  - 亮度 (Lux)
  - 表面温度 (K)
  - 距离 (光年)

**HUD 特性**:
- 跟随鼠标位置
- 3 秒后自动消失
- 航空风格蓝色边框
- 背景模糊效果

### 场景 3: 接近事件视界

**触发条件**: 
- 持续滚轮向下，使相机距离 < 3 单位

**视觉变化**:
1. 引力透镜效果加强
2. 吸积盘亮度增加
3. 黑洞中心越来越大
4. 星光扭曲更加明显

**物理效果**:
- 光线弯曲增强
- 时间膨胀效应
- 引力红移现象

### 场景 4: 进入黑洞内部

**自动触发**: 当相机距离 < 3 单位时自动进入

**内部景象**:
- 🌀 **无限折叠空间**: 递归反射的奇异空间
- 🎨 **色彩扭曲**: 蓝色、紫色、青色交织
- ⚡ **能量条纹**: 动态流动的光条
- 💫 **色散效果**: 光线分离成不同颜色
- 🌊 **旋涡扭曲**: 空间持续旋转变形

**操作提示**:
```
点击屏幕 = 开启/关闭 HUD 界面
ESC 键 = 退出黑洞
```

### 场景 5: 主 HUD 界面

**如何开启**: 在黑洞内部点击屏幕

**HUD 元素**:

1. **标题栏**
   - "BLACK HOLE TELEMETRY"
   - 棕黄色复古风格

2. **数据显示区**（4 个数据项）:

   a) **相机距离** (Camera Distance)
   - 单位: AU（天文单位）
   - 范围: 0.00 - 20.00
   - 进度条: 橙黄色

   b) **扭曲强度** (Distortion)
   - 倍数: 0.00x - 3.00x
   - 进度条: 红色
   - 越靠近黑洞越强

   c) **模拟重力** (Gravity)
   - 单位: G（地球重力）
   - 指数增长
   - 进度条: 紫色

   d) **时间膨胀** (Time Dilation)
   - 倍数: 1.00x - 11.00x
   - 进度条: 青色
   - 相对论效应

3. **状态指示器**
   - 🟢 绿色 NOMINAL: 正常状态（距离 > 5）
   - 🟡 黄色 WARNING: 警告状态（2 < 距离 < 5）
   - 🔴 红色 CRITICAL: 危险状态（距离 < 2）

4. **视觉效果**
   - 扫描线动画
   - 四角装饰框
   - 复古电子屏风格
   - 半透明背景

**HUD 操作**:
```
再次点击屏幕 = 关闭 HUD
ESC 键 = 同时关闭 HUD 并退出黑洞
滚轮 = 无效（黑洞内部不允许缩放）
```

### 场景 6: 退出黑洞

**退出方式**:
1. 按 ESC 键
2. 自动返回到外部场景（距离约 3.5 单位）

**退出效果**:
- 平滑过渡动画
- 内部场景消失
- 外部场景恢复显示
- HUD 自动关闭

## 完整操作流程示例

### 完整体验流程（约 2 分钟）

```
1. 进入页面 → 观察外部黑洞和吸积盘
   ↓
2. 点击几颗星星 → 查看星体数据
   ↓
3. 滚轮向下 → 慢慢接近黑洞
   ↓
4. 观察引力透镜变化 → 光线弯曲效果
   ↓
5. 继续靠近 → 自动进入黑洞（距离 < 3）
   ↓
6. 观察内部扭曲空间 → 色彩和折叠效果
   ↓
7. 点击屏幕 → 开启 HUD 界面
   ↓
8. 查看各项数据 → 观察状态变化
   ↓
9. 按 ESC → 退出黑洞
   ↓
10. 回到外部 → 继续探索
```

## 技术参数

### 可调参数（在代码中）

```typescript
// src/components/InterstellarBlackHole.vue

// 缩放范围
const minZoom = 2          // 最近距离
const maxZoom = 20         // 最远距离
const zoomSpeed = 0.1      // 缩放平滑度（0.1 = 慢, 0.5 = 快）

// 黑洞阈值
const eventHorizonThreshold = 3  // 进入黑洞的距离

// 星空参数
const starCount = 15000    // 星星数量（越多越卡）

// 吸积盘颜色
uColorHot: new THREE.Color(1.0, 0.9, 0.7)   // 高温色
uColorCool: new THREE.Color(1.0, 0.5, 0.2)  // 低温色
```

## 调试技巧

### 查看帧率
打开浏览器开发者工具（F12）→ Performance → 录制

### 修改 Shader 实时预览
1. 修改 `src/shaders/*.glsl` 文件
2. 保存后 Vite 会自动热更新
3. 刷新页面查看效果

### 常见问题

**Q: 黑屏/白屏?**
A: 检查浏览器控制台是否有错误，可能是 WebGL 不支持

**Q: 性能很卡?**
A: 减少 `starCount` 数值，或降低屏幕分辨率

**Q: 点击星星没反应?**
A: 确保点击的是星星区域（避开黑洞中心）

**Q: HUD 不显示?**
A: 确保已进入黑洞内部（滚轮靠近到自动进入）

**Q: 无法退出黑洞?**
A: 按 ESC 键，如果不行刷新页面
